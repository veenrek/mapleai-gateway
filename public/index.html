Quickstart

Drop-in replacement for OpenAI/Anthropic SDKs.

Python SDK

Use the OpenAI SDK pointing to our endpoint.

# pip install openai
from openai import OpenAI

client = OpenAI(
  base_url="https://sol.mapleai.shop/v1",
  api_key="not-needed"  # x402 handles payment
)

response = client.chat.completions.create(
  model="anthropic/claude-opus-5",
  messages=[{"role": "user", "content": "Hello Claude"}]
)
print(response.choices[0].message.content)

TypeScript / Node.js

Same OpenAI SDK, different base URL.

// npm install openai
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://sol.mapleai.shop/v1',
  apiKey: 'not-needed'  // x402 payment
});

const response = await client.chat.completions.create({
  model: 'anthropic/claude-opus-5',
  messages: [{role: 'user', content: 'Hello'}]
});
console.log(response.choices[0].message.content);

cURL (with x402 payment)

First call returns 402 with price, retry with USDC payment signature.

curl https://sol.mapleai.shop/v1/chat/completions \
  -H 'content-type: application/json' \
  -d '{
    "model": "anthropic/claude-opus-5",
    "messages": [{"role": "user", "content": "Hi"}]
  }'

# 402 Payment Required
# Response includes USDC amount + payment details
# Sign with your Solana wallet, retry with signature

Payment

x402 protocol — priced upfront, settled on-chain.

  1. Request without payment

    Send your OpenAI-compatible request to our endpoint. No auth header needed.

  2. Receive 402 with exact price

    The response includes the precise USDC amount for your token count, the treasury address, and a recent blockhash.

  3. Sign & retry with payment

    Your wallet signs the USDC transfer. The facilitator co-signs as fee payer (no SOL needed). Retry the request with the signature — it runs immediately.
