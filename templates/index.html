Python SDK

Use an x402-aware HTTP client to attach a payment signature.

# pip install openai
from openai import OpenAI

client = OpenAI(
  base_url="{{API_BASE}}",
  api_key="payment-signature-required"  # use an x402 client
)

response = client.chat.completions.create(
  model="{{DEFAULT_MODEL}}",
  messages=[{"role": "user", "content": "Hello"}]
)
print(response.choices[0].message.content)

TypeScript / Node.js

An x402 client must sign and retry after the 402 challenge.

// npm install openai
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: '{{API_BASE}}',
  apiKey: 'payment-signature-required'  // use an x402 client
});

const response = await client.chat.completions.create({
  model: '{{DEFAULT_MODEL}}',
  messages: [{role: 'user', content: 'Hello'}]
});
console.log(response.choices[0].message.content);

Payment

x402 protocol — priced upfront, settled on-chain.

  1. Request without payment

    Send your OpenAI-compatible request to our endpoint. No auth header needed.

  2. Receive 402 with exact price

    The response includes the precise {{ASSET}} amount for your token count, the treasury address, and the accepted payment scheme.

  3. Sign & retry with payment

    Your wallet signs the {{ASSET}} transfer. The facilitator co-signs as fee payer (no native gas needed). Retry the request with the signature — it runs immediately.
