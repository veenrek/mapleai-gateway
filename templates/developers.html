cURL

Request the resource once to receive the exact amount and payment requirements in the PAYMENT-REQUIRED header. Sign those requirements with an x402 wallet, then retry with PAYMENT-SIGNATURE.

Get the payment quote
curl -i {{API_BASE}}/chat/completions \
  -H 'content-type: application/json' \
  -d '{"model":"{{DEFAULT_MODEL}}","messages":[{"role":"user","content":"Hello"}],"max_tokens":64}'
Retry with a signed x402 payload
curl {{API_BASE}}/chat/completions \
  -H 'content-type: application/json' \
  -H "PAYMENT-SIGNATURE: $PAYMENT_SIGNATURE" \
  -d '{"model":"{{DEFAULT_MODEL}}","messages":[{"role":"user","content":"Hello"}],"max_tokens":64}'

Use the same request body for both calls. PAYMENT_SIGNATURE is the base64 x402 payment payload signed by your wallet.

JavaScript

Use the x402 SDK to sign the 402 challenge. Set EVM_PRIVATE_KEY for an EVM wallet, or provide a Solana keypair signer on Solana. The example caps payments at 0.10 USDC on EVM networks.

Node.js 20+
{{DEVELOPER_JAVASCRIPT}}

const url = '{{API_BASE}}/chat/completions';
const body = JSON.stringify({
  model: '{{DEFAULT_MODEL}}',
  messages: [{ role: 'user', content: 'Hello' }],
  max_tokens: 64
});
const headers = { 'content-type': 'application/json' };
const first = await fetch(url, { method: 'POST', headers, body });
if (first.status !== 402) throw new Error('Expected payment challenge');
const challenge = JSON.parse(Buffer.from(
  first.headers.get('payment-required'), 'base64'
).toString());
if (challenge.resource.url !== url || challenge.accepts[0].network !== '{{NETWORK}}') {
  throw new Error('Unexpected payment request');
}
const payload = await client.createPaymentPayload(challenge);
delete payload.extensions?.quote; // optional display metadata is not required to settle
const signature = Buffer.from(JSON.stringify(payload)).toString('base64');
const paid = await fetch(url, {
  method: 'POST',
  headers: { ...headers, 'PAYMENT-SIGNATURE': signature },
  body
});
if (!paid.ok) throw new Error('Request failed: ' + paid.status);
console.log(await paid.json());

Install the x402 packages for your network. On EVM: npm install @x402/core @x402/evm viem. On Solana: npm install @x402/svm @solana/kit @scure/base. Keep private keys outside source code.
