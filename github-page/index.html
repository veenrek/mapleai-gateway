Quickstart

OpenAI-compatible requests with x402 payment. An x402-aware client must sign and retry after the 402 challenge.

Free embeddings API — no key, no account
Run an example using free embeddings and paid GPT

Python SDK

Use an x402-aware HTTP client to attach a payment signature.

# pip install openai
from openai import OpenAI

client = OpenAI(
  base_url="https://sol.mapleai.shop/v1",
  api_key="payment-signature-required"  # use an x402 client
)

response = client.chat.completions.create(
  model="openai/gpt-5.6-sol",
  messages=[{"role": "user", "content": "Hello"}]
)
print(response.choices[0].message.content)

TypeScript / Node.js

An x402 client must sign and retry after the 402 challenge.

// npm install openai
import OpenAI from 'openai';

const client = new OpenAI({
  baseURL: 'https://sol.mapleai.shop/v1',
  apiKey: 'payment-signature-required'  // use an x402 client
});

const response = await client.chat.completions.create({
  model: 'openai/gpt-5.6-sol',
  messages: [{role: 'user', content: 'Hello'}]
});
console.log(response.choices[0].message.content);

cURL (with x402 payment)

First call returns 402 with the price, retry with a USDC payment signature.

curl https://sol.mapleai.shop/v1/chat/completions \
  -H 'content-type: application/json' \
  -d '{
    "model": "openai/gpt-5.6-sol",
    "messages": [{"role": "user", "content": "Hi"}]
  }'

# 402 Payment Required
# Response includes the USDC amount + payment details
# Sign with your wallet, retry with the signature

Payment

x402 protocol — priced upfront, settled on-chain.

  1. Request without payment

    Send your OpenAI-compatible request to our endpoint. No auth header needed.

  2. Receive 402 with exact price

    The response includes the precise USDC amount for your token count, the treasury address, and the accepted payment scheme.

  3. Sign & retry with payment

    Your wallet signs the USDC transfer. The facilitator co-signs as fee payer (no native gas needed). Retry the request with the signature — it runs immediately.
